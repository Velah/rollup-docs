Privacy notice · release candidate

Report data stays with the Confluence macro.

This notice describes the audited development release candidate as of 19 September 2026. It will be reviewed again before Marketplace submission.

Current status

Rollup is under development and is not yet publicly listed in Atlassian Marketplace. This is a publishable release-candidate notice, not a claim of Marketplace approval.

Operator and contact

Rollup is operated by Xavier Velasco Llauradó, an individual based in Spain. For privacy, support, or security questions, contact velasco.llaurado@gmail.com.

What the app processes

Authors may enter or import report names, column names, cell values, formulas, grouping choices, and summary choices. Rollup processes that data to render the macro editor and reader.

Where app data goes

The release candidate saves the report document in the Confluence macro configuration through Atlassian Forge. Calculations run in the signed-in user’s browser. The audited app has no vendor-operated application server, database, analytics, telemetry, advertising, or external network egress.

Because the report is part of Confluence content, access, page history, retention, exports, backups, and deletion are governed by the customer’s Atlassian site configuration and Atlassian’s services. Space and page administrators should apply suitable Confluence permissions to sensitive reports.

What the app does not intentionally collect

The release candidate does not intentionally send report contents, formula values, user identifiers, or usage events to the developer. It does not set its own analytics cookies or embed third-party tracking resources.

Support communications

If you email support, the developer receives the information you choose to send, such as your email address, app version, error text, and troubleshooting context. Do not send confidential report data, credentials, authentication tokens, or real CSV files. Support correspondence is used to investigate and respond to the request.

This documentation website

These static pages contain no developer-added analytics, tracking scripts, remote fonts, or third-party media. This website is hosted by GitHub Pages. Like other hosting providers, GitHub may process technical access and security logs, including visitor IP addresses, under GitHub’s Privacy Statement. Those website-host records are separate from report data handled by the Confluence app.

Deletion and uninstall

The app does not maintain a separate vendor database to delete. Removing a macro or Confluence page removes it according to the site’s Atlassian content lifecycle. In a development uninstall test on 19 September 2026, existing reports stopped rendering and Confluence retained a blank macro area; reinstalling the same app restored rendering without changing the page body or version. This is scoped test evidence, not a guarantee about every Atlassian retention or backup system.

Security and questions

Report a suspected vulnerability privately to velasco.llaurado@gmail.com. Include a concise reproduction and impact, but no secrets or real customer data. See the support page for details.
