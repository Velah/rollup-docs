User guide

Build a rollup from source rows.

Create the table, add calculated columns, choose the grouping order, and save. Readers get the same values and explanations you see in the editor.

Release status

This guide describes the development release candidate tested on 19 September 2026. Rollup is not yet listed in Atlassian Marketplace.

1. Add the macro and source rows

  1. Insert Rollup Table on a Confluence page.
  2. Name the report and its data columns.
  3. Type values into the rows or choose a UTF-8 CSV file.
  4. Review calculations and grouping, then choose Save table.
  5. Publish or update the Confluence page so readers can open the saved result.

CSV uses its first row as column names. A compatible import preserves calculated columns, grouping, and summaries. If the source shape is incompatible, Rollup explains which configuration would reset and waits for review before replacing rows. Invalid CSV leaves the existing draft intact.

2. Add calculated columns

Choose + Formula column, give it a unique name, and enter a formula. Column names appear in square brackets. A leading = is optional.

  • [Seats] * [Unit price]Multiply two numeric columns.
  • ([List price] - [Discount]) * [Seats]Control arithmetic order with parentheses.
  • DATEDIFF([Start], [End])Return calendar days between two date columns.
  • DATEDIFF("2026-01-01", "2026-01-31")Use quoted date text for literal dates.
  • IF([Cost] >= 100, "Review", "Within budget")Return text from a condition.
  • IF([Seats] = 0, 0, 10 / [Seats])Avoid division by zero; IF evaluates only its selected branch.

Formula rules

  • Arithmetic operators are +, -, *, and /.
  • Comparisons are =, !=, <, <=, >, and >=.
  • Decimals use a dot without thousands separators: 1200.50. A value such as 1,200.50 is rejected as nonnumeric.
  • Text uses double quotes. Double a quote inside text: "He said ""yes""".
  • Boolean literals are TRUE and FALSE. Boolean comparisons support = and !=.
  • Text comparisons are case-sensitive and locale-independent.
  • Dates must be quoted or come from a column, use exactly YYYY-MM-DD, and exist in the UTC calendar. Leap years are checked.
  • Blank cells count as zero in arithmetic and numeric comparisons.
  • Formula columns can reference earlier or later calculated columns. Missing references and circular dependencies are errors, including inside a branch IF does not select.

3. Group and summarize

In Group and summarize, add grouping columns in the order readers should see them. For example, Vendor followed by Cost centre produces one vendor section with cost-centre sections inside it.

Add any of these summaries to a source or calculated column:

SUMAdd numeric values.
AVGAverage numeric values.
COUNTCount nonblank values, including text, booleans, and zero.
MIN / MAXFind the smallest or largest numeric value.

Blank values are skipped by summaries. A nonnumeric value or formula error makes a numeric summary show an explanation instead of a misleading partial answer. Grand totals summarize source rows once, even when the report has several grouping levels. Text-only and boolean-only columns are omitted from numeric grand totals.

Understand errors

Formula syntax is checked while you type. Save stays disabled until syntax and reference errors are fixed. At runtime, the affected cell explains errors such as a nonnumeric value, division by zero, an impossible date, or a nonboolean IF condition. Dependent calculated cells and summaries carry that explanation forward.

The editor and published reader use the same calculation path. On 19 September 2026, the development installation was checked with numeric-format, division-by-zero, impossible-date, and nonboolean-IF failures; both surfaces showed matching errors.

Limits and large reports

RowsUp to 10,000 per report.
ColumnsUp to 100.
Cell textUp to 10,000 characters.
FormulaUp to 2,000 characters.
Saved report4.5 MB serialized configuration safety budget.
CSV file10 MB input limit.

A synthetic 5,000-row, 9-column fixture was saved, published, and reloaded in development on 19 September 2026. It preserved exact CSV rows, three formulas, two grouping levels, and five summaries. The saved report JSON measured 1,066,756 bytes; the enclosing macro configuration JSON measured 1,216,977 bytes. This one fixture shows tested behavior, not a promise that every report under the limits has the same speed or size.
