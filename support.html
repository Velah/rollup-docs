Support and security

Send the error, context, and safe reproduction.

Contact velasco.llaurado@gmail.com for product support or to report a suspected vulnerability privately.

Product support

Include the following when it is safe to do so:

  • whether the problem appears while editing or reading a published page;
  • the exact visible error message;
  • the shortest formula or synthetic CSV example that reproduces it;
  • the sequence of actions before the problem;
  • your browser family and approximate version; and
  • whether reloading the page changes the result.
Keep sensitive data out of email.

Do not send credentials, API tokens, tax or identity records, confidential Confluence content, real customer CSV files, or screenshots that expose account details. Replace names and values with synthetic examples.

Before contacting support

  1. Read the cell’s explanation; formula failures identify the affected value.
  2. Check decimal formatting and strict YYYY-MM-DD dates.
  3. Confirm every [Column name] still exists and is spelled exactly.
  4. If Save is disabled, fix the formula message shown beneath the calculated column.
  5. If access is blocked, ask a site admin to check the app subscription and reload the page.

The user guide contains formula recipes, summary behavior, and report limits.

Private security reports

Email velasco.llaurado@gmail.com with “Private Rollup security report” in the subject. Explain the affected surface, prerequisites, steps to reproduce with synthetic data, expected impact, and any suggested mitigation. Do not test against data or sites you do not own or have permission to assess.

The report will be acknowledged, triaged, and investigated. Confirmed issues will be contained and remediated according to severity, then retested before a release. Customer or Marketplace notifications will follow the facts and applicable obligations. Specific response-time commitments have not yet been published.

Development availability

Rollup is not yet listed in Atlassian Marketplace, so there is currently no public install link, paid subscription, or Marketplace review channel. This page will be updated if that changes.
